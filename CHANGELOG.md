## [Unreleased]

### Added
- Fail2ban dashboard expanded to 7 panels: sparklines on current bans and failed attempts, new "Attacks last 24 h" and "Total attacks blocked" panels.
- Alert `Fail2banSocketDown` when `f2b_up == 0`. The exporter process can stay up while the socket is unreachable, so a Prometheus `up` check does not cover this.

### Changed
- All dashboards filter by job name dynamically — no hardcoded job names. Works with any scrape job name in `prometheus.yml`.
- `HighLoadAverage` alert fixed: now correctly matches CPU count per instance.
- `Fail2banHighAttackRate` alert updated to use `f2b_jail_banned_total` metric (matches hctrdev exporter).
- `docs/FAIL2BAN_ENHANCED.md`: image `0.10.3` runs as uid 0. The guide mounts `/var/run/fail2ban` read-only, scrapes `fail2ban-exporter:9191` on the Compose network, and does not change socket permissions. A `RuntimeDirectoryPreserve=yes` drop-in keeps the directory across `systemctl restart fail2ban`; without it `f2b_up` stays 0 until the exporter container restarts.
- Dashboards are generated by `scripts/build-dashboards.py` — do not edit JSON files directly.

### Removed
- `docs/PRODUCTION_CHECKLIST.md` — content merged into SECURITY.md and OPERATIONS.md.

## [2.2.0] - 2026-10-04

### Fixed
- `docker compose up` starts the full stack correctly: Prometheus, Grafana, Alertmanager, Node Exporter, and Blackbox on port 3001.
- Alertmanager works without a Telegram token configured.
- Provisioned dashboards connect to Prometheus automatically on first start.

### Security
- Stack refuses to start without `GRAFANA_PASSWORD`. No default password.
- All image tags pinned to stable releases.
- Dashboard edits from the Grafana UI are disabled; `grafana-dashboards/json/` is the only source of truth.

## [2.0.0] - 2026-09-30

### Added
- `ansible/` — Ansible playbook and roles for one-command deployment.
- `grafana-dashboards/json/` — 7 pre-built dashboard JSON files, provisioned automatically.
- `alerts/alertmanager.example.yml` — alert routing configuration template.
- `scripts/backup-monitoring.sh` — automated backup script with optional cron setup.
- `scripts/fetch-dashboards.sh` — dashboard management script.
- `fail2ban/` — fail2ban integration guide and configuration.
- 20 documentation guides: ALERTMANAGER, BACKUP, BLACKBOX, DASHBOARD_IMPORT, DEPLOYMENT, FAIL2BAN_ENHANCED, GRAFANA_DASHBOARDS, MONITORING, MULTI_SERVER, NGINX_MONITORING, OPERATIONS, POSTGRESQL_MONITORING, QUICK_REFERENCE, RABBITMQ_MONITORING, REDIS_MONITORING, RUNBOOK, SECURITY, TROUBLESHOOTING, UPGRADE, INDEX.
- CI: YAML validation job for Ansible configs and alert rules; ShellCheck job for `scripts/`.
- CI: `concurrency` group with cancel-in-progress.

### Changed
- Full stack open-sourced: Ansible, dashboards, alert rules, and all documentation in one repository.
- README rewritten: community-first structure, Quick Start section, architecture diagram.
- INSTALLATION_GUIDE covers both Docker Compose and Ansible deployment paths.

### Removed
- Commercial documentation (PURCHASE, SERVICES, FEATURES comparison).
