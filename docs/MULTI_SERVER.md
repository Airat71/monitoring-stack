# MULTI_SERVER — Adding and managing multiple hosts

- **Monitoring server:** One host runs the full stack (Prometheus, Grafana, Alertmanager, Node Exporter, Blackbox). Set this host in the `monitoring_server` group. Its Node Exporter container publishes `127.0.0.1:9100`. Prometheus scrapes `node-exporter:9100` on the Compose network, so that loopback port is not used for remote scrapes.
- **Monitored nodes:** Other hosts need only Node Exporter. Add them under `monitored_nodes` with `ansible_host` set to an IPv4 address the monitoring server can open. The exporter listens on that address at port 9100. `127.0.0.1:9100` on those hosts would not accept the monitoring server's connection.
- **Firewall:** The node role allows TCP 9100 only from the monitoring server. It does not enable UFW and does not change the policy for SSH. If Prometheus connects from a different address than `ansible_host` of `monitoring_server` (NAT), set `node_exporter_allow_from` to that source address. Local requests from the host itself (`curl` to its own address) are allowed. The host needs `iptables`. The port is fixed at 9100; the firewall rule and the Prometheus scrape target use it.
- **Discovery:** The Ansible Prometheus template adds every host in `monitored_nodes` as a scrape target for the `node-exporter` job. If a node's exporter listens on an address other than `ansible_host`, set `node_exporter_bind_ip` for that host; the scrape target uses it. Re-run the playbook after adding or removing nodes. When `prometheus.yml` or the alert rules change, the playbook restarts the Prometheus container, because the files are single-file bind mounts and a reload would keep reading the old content.
- **systemd or Docker:** `node_exporter_install_method` is `docker` by default. Set `systemd` on a host that should run the binary instead. The systemd method downloads the official archive for `x86_64` or `aarch64` and verifies its pinned sha256 (`node_exporter_checksums`). The unit listens on `ansible_host` and does not use `/host/proc`. To switch a host that already runs the other method, stop and remove the old unit first, otherwise it keeps port 9100.
- **Optional services:** Nginx, PostgreSQL, Redis, and RabbitMQ dashboards ship in the repository. The playbook does not install those exporters. Add the exporter and a scrape job yourself; until then the dashboard is empty.
